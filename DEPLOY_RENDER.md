TAW — публикация веб-приложения в интернете (Render)
====================================================

Этот пакет подготовлен для размещения приложения в Render. Приложение использует
только стандартную библиотеку Python; внешние Python-пакеты устанавливать не нужно.

ВАЖНО О ПУБЛИЧНОМ ДОСТУПЕ
------------------------
После публикации ссылка будет доступна через интернет всем, кто её знает (если не
настроить дополнительную защиту). Не добавляйте в репозиторий пароли, токены или
личные данные. Приложение запрашивает только публичные страницы tacticalairwar.com,
но пользователи публичного сайта могут запускать обновление статистики.

ШАГ 1. Создайте репозиторий на GitHub
------------------------------------
1. Откройте https://github.com/ и войдите или создайте аккаунт.
2. Создайте новый репозиторий, например taw-squad-stats.
3. Репозиторий можно сделать Private; тогда на следующем этапе подключите свой GitHub
   аккаунт к Render и предоставьте ему доступ к этому репозиторию.
4. Загрузите в корень репозитория файлы server.py, index.html, render.yaml,
   .python-version, requirements.txt, .gitignore и файл DEPLOY_RENDER.md.
5. Загрузите папку lists целиком с файлами списков техники.

Структура репозитория должна быть такой:
  server.py
  index.html
  render.yaml
  .python-version
  requirements.txt
  .gitignore
  lists/
    heavy_plane.txt
    heavy_t.txt
    light_plane.txt
    light_t.txt
    middle_plane.txt
    middle_t.txt

Не загружайте папку .taw_cache — это временный кэш, он создастся автоматически.

ШАГ 2. Создайте сервис Render
-----------------------------
Рекомендуемый путь через конфигурацию render.yaml:
1. Откройте https://render.com/ и войдите/создайте аккаунт.
2. Подключите GitHub, если Render попросит.
3. В панели Render выберите New + → Blueprint (название пункта интерфейса может
   немного отличаться) и укажите созданный репозиторий.
4. Render прочитает render.yaml. Убедитесь, что выбран план Free, затем запустите
   создание сервиса.

Если не предлагается Blueprint, создайте New + → Web Service, выберите репозиторий
и выставьте вручную:
  Runtime: Python 3
  Build Command: python -m compileall -q server.py
  Start Command: python server.py
  Instance Type/Plan: Free (для пробного запуска)
  Health Check Path: /api/health

В настройках окружения можно оставить PYTHON_VERSION=3.13.5; файл .python-version
также фиксирует версию Python.

ШАГ 3. Проверьте публикацию
---------------------------
1. Дождитесь статуса Live/Succeeded в Render.
2. Откройте адрес сервиса вида https://имя-сервиса.onrender.com.
3. Проверьте, что открывается интерфейс TAW.
4. Вставьте ссылку на страницу сквада, например:
   https://tacticalairwar.com/squad_stats.php?name=72%20Air%20Group
5. Нажмите «Загрузить данные». При первой загрузке обработка журналов может занять
   несколько минут. Логи процесса можно посмотреть в разделе Logs сервиса Render.

Что важно для бесплатного тарифа Render:
- После 15 минут без входящих запросов сервис засыпает; первое открытие после этого
  может занять примерно минуту.
- Файловая система бесплатного сервиса временная. Кэш потеряется при перезапуске или
  новом развёртывании, но приложение заново создаст его автоматически.
- Данные состояния хранятся в памяти одного экземпляра. Не масштабируйте сервис на
  несколько экземпляров без изменения архитектуры.
- Бесплатный тариф годится для проверки/небольшого проекта и имеет ограничения.

Если сайт TAW изменит HTML или блокирует частые запросы, загрузка может завершаться
предупреждениями. Сначала проверьте Logs и сообщение на странице.
